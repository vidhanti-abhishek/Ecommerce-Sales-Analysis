# 📊 Ecommerce Sales Analysis Dashboard | Microsoft Excel

## 📌 Project Overview

The **Ecommerce Sales Analysis Dashboard** is a dynamic and interactive dashboard developed using Microsoft Excel to analyze sales performance, profitability, product categories, and regional sales trends.

The dashboard provides a comprehensive overview of business performance through interactive charts, KPI cards, and filters, helping users explore sales data and make data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track year-over-year (YoY) growth in key business metrics.
- Identify profitable product categories and subcategories.
- Analyze sales performance across different states.
- Monitor order quantity and profit margins.
- Provide interactive data visualization for business analysis.

## 📊 Dashboard Features

### 1. Sales and Profit Analysis
Visualizes monthly sales and profit performance to identify trends and patterns over time.

### 2. Category-Wise Profit Analysis
Compares profitability across major product categories:
- Technology
- Office Supplies
- Furniture

### 3. Category-Wise Sales Share
Displays each product category's contribution to total sales using a doughnut chart.

### 4. Sales by State
Uses a geographical map to visualize sales performance across different states.

### 5. Top 10 Subcategories
Highlights the top-performing product subcategories based on sales.

### 6. Interactive Filters
Allows users to dynamically filter the dashboard by:
- Year
- Region
- Customer Segment

All relevant dashboard visuals update according to the selected filters.
